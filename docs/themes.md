# 节日主题美术资源说明

步步会在节日自动切换外观。现在每个节日用的是程序画的**占位图形**；正式美术资源做好后，按下面的方式放进来即可，**不需要改代码**。没有登记资源的节日继续使用占位图形。

## 放在哪里

```
public/themes/
  manifest.json          ← 登记表
  spring_festival/
    overlay.svg          ← 春节的叠加图
  mid_autumn/
    overlay.png
  ...
```

改完后重新构建（`npm run build` 或 CI）即可生效。在浏览器里打开 `npm run dev` 的地址，页面底部的“节日主题”一栏会显示每个节日实际用的是图片还是占位图形；也可以在应用的“设置 → 节日主题 → 预览”里随时切换查看。

## manifest.json

```json
{
  "version": 1,
  "themes": {
    "spring_festival": { "overlay": "spring_festival/overlay.svg", "layer": "front", "accent": "#d8342a" },
    "mid_autumn": { "overlay": "mid_autumn/overlay.png", "layer": "back" }
  }
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `overlay` | 否 | 相对 `public/themes/` 的路径，SVG 或 PNG。不填就继续用占位图形 |
| `layer` | 否 | `front`（默认）画在宠物身前；`back` 画在宠物身后（比如背景里的月亮、灯笼串） |
| `accent` | 否 | 节日祝福气泡的边框颜色，不填用内置颜色 |

## 画布规格

- 叠加图和宠物共用同一个 **120 × 120** 的坐标系，图片会被拉伸到 120 × 120 覆盖在宠物上，所以请按 120 × 120（或等比放大，比如 480 × 480 的 PNG）作画，背景透明。
- 宠物身体大约占 x 20–100、y 36–108；头顶小芽在 x 45–80、y 15–38；脚底在 y 110 左右。
- 可以画到画布外一点点（比如灯笼挂在头顶上方），超出部分仍会显示，但不会响应鼠标点击。
- 宠物朝左走时整张图会水平镜像，**不要在图里放文字**（镜像后会反）。
- 宠物会做各种动作（跳、晃、举手），叠加图跟着身体整体移动，不会单独跟着手动。手里拿的东西请画在身体两侧，不要画在手的位置。
- PNG 建议控制在 50 KB 以内，SVG 尽量精简。所有节日资源加起来不应超过 1 MB，避免拖慢启动和占用内存。

## 节日 id 一览

| id | 节日 | 生效日期 |
| --- | --- | --- |
| `spring_festival` | 春节 | 除夕到正月初七 |
| `lantern` | 元宵节 | 正月十五 |
| `qingming` | 清明 | 清明节气当天 |
| `dragon_boat` | 端午节 | 五月初五 |
| `qixi` | 七夕 | 七月初七 |
| `mid_autumn` | 中秋节 | 八月十五及前后一天 |
| `double_ninth` | 重阳节 | 九月初九 |
| `new_year` | 元旦 | 12 月 31 日到 1 月 1 日 |
| `valentine` | 情人节 | 2 月 14 日 |
| `labor_day` | 劳动节 | 5 月 1 日到 5 日 |
| `children` | 儿童节 | 6 月 1 日 |
| `national_day` | 国庆节 | 10 月 1 日到 7 日 |
| `halloween` | 万圣节 | 10 月 31 日 |
| `christmas` | 圣诞节 | 12 月 24 日到 25 日 |
| `custom` | 用户自定义的纪念日（比如生日） | 用户设置的日期当天 |

几个节日日期重叠时：节日正日子优先，其次按上表顺序（比如中秋和国庆重叠时，中秋前后一天显示中秋，其余日子显示国庆）。农历日期由 [tyme4rs](https://crates.io/crates/tyme4rs) 换算。
